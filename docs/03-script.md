# 03 剧本架构

照抖音「星际探索馆」（外星人 + 普通男生，养生科普，几十万粉）逐句拆出来的架构。**只学结构，不搬台词。**

## 整集骨架

| 位置 | 做什么 | 例子（睡觉 vs 健身） |
| --- | --- | --- |
| 0–10 秒 | **钩子**：主角念出一个说法或问题，陪伴角色剧透一半，埋下「代价」（伏笔①，结尾揭晓） | 阿杰刷手机：「睡觉比健身重要一万倍？」啵啵：「一万倍是夸张了。但少睡去健身最大的代价，打卡帖里没人提。剧透一句：跟你练的肉留不留得住有关。」 |
| 10–20 秒 | **立 flag + 打赌**：主角定一个挑战（N 天），陪伴角色赌他会「来求我」 | 「每天只睡 5 小时，坚持 100 天！」「我赌你 100 天后，来求我。」 |
| 20–30 秒 | **预告悬念**（伏笔②）：「先熬过第 X 天，那天会……，多少先不告诉你」+ 陪伴角色的机制（扫描、报数） | 「先熬过第三天吧，那天你会饿到怀疑人生。」 |
| 中间 | **时间线 5–8 站**，每站同一个套路（见下） | 第 1 / 3 / 7 / 21 / 50 / 100 天 |
| 中间穿插 | **评论区互动**一次 | 「你们地球人一般几点睡？评论区报个时间。」 |
| 中间穿插 | **金句伏笔③**：一个比喻 +「这句话 N 天后我要考你」 | 「练是在拆房子，睡才是在盖房子。」 |
| 中间穿插 | **意外事件**：顺手暗埋代价的线索 | 感冒了，「好在肌肉还在」「肌肉？你等着瞧。」 |
| 中间穿插 | **后面的站回扣前面的数字** | 第 100 天：「第三天那份饿，第七天那节电池，你一天都没缓过来。」 |
| 最后一站 | **求饶 + 赌约兑现**：主角「我求你了，怎么才能……」→「你求我了，我赢了。答案是：……」 | 「答案是：没有这种办法。」 |
| 接着 | **加码 + 揭晓伏笔①**：主角想更狠 →「打住，再这样下去开头那个代价就真来了」→「什么代价？」 | 「那我只睡 4 小时，一天练两遍！」 |
| 揭晓 | **第一 / 第二 / 第三**，主角追问推进：第一兑现伏笔①、回扣前面的数字；第二给反方向的研究，防止说过头；第三最扎心（心态 / 判断），回扣第 1 天 | 第二：「没有一万倍。运动够量，能抵消睡得差的大部分坏处。前提是，别拿睡觉去换它。」 |
| 收尾 | 「所以我白熬了？」「没白熬，你戒掉的是 A，不是 B」+ 回扣伏笔③ | 「你戒掉的是赖床，不是睡觉。」 |
| 结尾 | **下期新赌约**：主角换一个挑战，陪伴角色赌他第几天破功 →「关注我，下期接着赌」 | 「下一个 100 天，我改戒奶茶！」「我赌你第二天下午就点外卖。」 |

## 每一站的套路

1. 【字卡：第 N 天】主角做一件事，或搬出一个流行说法 / 网上博主的话（冲冷水澡、周末补觉、「21 天养成习惯」、健身教练说……）
2. 陪伴角色「扫描完毕 / 数据更新」：先一句反转，再给数字（「有个实验……」）
3. **借一个物体钻进比喻场景**：冰箱灯、杠铃孔、闹钟表盘、喷嚏飞沫、体重秤屏幕、主角的眼睛……镜头推进去，穿出来已经在场景里。两人一起站在场景里
4. **一句台词配一个新画面**：数字往上跳就拍仪表盘指针甩上去，「掉的是肌肉」就拍红箱子被一车车拉走
5. 主角夸张推论（「那我多睡会儿，岂不是躺着就瘦了？」）→ 陪伴角色一句冷幽默打回去（「想多了。睡够了，只是不帮倒忙。」）

## 伏笔清单（写在 episode.json 的 hooks 里）

- ① 开头的代价 → 结尾第一点揭晓
- ② 第 X 天的悬念 → 那一站兑现 → 后面再回扣一次
- ③ 金句比喻 → 结尾回扣，最好让比喻场景再出现一次（工地白天拆墙 → 夜里工人进场砌墙）
- ④ 主角第 1 天的一句嘴硬 → 第三点回扣

## 角色分工

- **主角**是观众的嘴：说大家常见的做法和网上的说法，嘴硬、爱推论、会崩溃求饶
- **陪伴角色**只说数据和冷幽默，从不讲大道理；口头禅固定几个（「扫描完毕」「我赌你……」），但不要用别人账号的原话

## 写进 episode.json

每段 8 个镜头，每个镜头：

| 字段 | 写什么 |
| --- | --- |
| `dur` | 秒数，至少 2 秒；台词按每秒 4–5 个字算 |
| `place` | 在哪。和 `series.json` / `episode.json` 里有图场景的 `name` 一字不差时，会自动带上那张参考图 |
| `cast` | 画面里有谁（角色 id）；画外音的人不算 |
| `cast_note` | 特殊情况自己写，比如「阿杰 1 个，镜子里是他变老的倒影，没有啵啵」「没有阿杰，也没有啵啵，只有工人」 |
| `desc` | 视频里这一镜：景别、谁在哪、做什么 |
| `panel` | 分镜这一格要和 `desc` 不一样时才写（比如 desc 里有「突然出现」这种静态图画不出的动作） |
| `lines` | 台词：`who`、`text`、画外音写 `"vo": true` |
| `sfx` | 音效 |
| `link` | 和上一个镜头是一个连续镜头时写怎么接（「镜头推进冰箱灯的白光，白光散开后已经在控制室里」）；每段第 1 个镜头不能写 |
| `card` | 剪辑时加的字卡（「第 7 天」） |

段级字段：`title`、`continuity`（这一段额外的连贯要求）、`text_note`（哪些字可以模糊）。
