# 01 角色和大本营

## 两个角色

| | 主角 | 陪伴角色 |
| --- | --- | --- |
| 是谁 | 普通年轻人（程序员、上班族、学生） | 懂身体的「外来者」：外星人（默认）、机器人、未来医生…… |
| 作用 | 观众的嘴：嘴硬、立 flag、信网上的说法、会崩溃求饶 | 只说数据和冷幽默，从不讲大道理 |
| 招牌 | 一个爱立 flag 的口头习惯 | 一个能「看进身体」的能力：额头印记扫描、投全息屏 |

## 外形怎么写

- 写实风格，人形，和人一样高（站在一起、过肩对话才自然）
- 写死：脸型、发型、眼睛、肤色、衣服的颜色和款式、一个记号（额头印记、发光细纹）
- 和主角的配色不撞：主角暖灰，陪伴角色冷色
- `short` 写一句简称（「和人一样高的人形外星人」），分镜提示词里用
- `voice` 写清楚声音：性别、年龄感、语速、性格（「冷静的成年女声，语速慢，带点损」）

## 原创

只学别人的号的剧情架构，不搬长相。比如「星际探索馆」的外星人是银灰皮肤、头顶骨脊、紫眼睛、白色高领服；我们的啵啵是同一类（人形、写实、冷静），但皮肤、头型、眼睛、记号、衣服都换掉。

## 设定图

`make_prompts.py SERIES sheets` 生成：全身三视图 + 正脸大特写（写实风脸部特写多，脸最容易走样）+ 4 个说话表情 + 2 个动作。出图后检查：

- 每个格子里的脸、衣服是不是同一个人
- 有没有多手多脚、乱码字
- 和 `look` 对不对得上

## 大本营

主角的房间，每段都会回来。`views` 写两个角度（朝窗户、朝门口），一张图里放左右两格，过肩镜头来回切时房间才对得上，而且只占一个参考图名额。
