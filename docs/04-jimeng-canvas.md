# 04 即梦画布里怎么操作

全部在即梦（海外用 Dreamina）的**画布**里做：每张图是一个节点，框选几个节点再生成，就是把它们当参考图。

## 画布怎么排

- 最上面一排：固定图（主角、陪伴角色、大本营，以及这集反复出现的场景，比如工地）
- 下面每段一列：分镜节点 → 视频节点，节点名写「第 N 段分镜」「第 N 段视频」
- 10 段也不会乱；各段互不依赖，可以同时排队生成

## 第一次：设定图

1. 新建画布 → 图片生成，比例 16:9
2. 复制 `设定图提示词.md` 里的整段，出 4 张挑 1 张
3. 下载存进 `refs/`（文件名和 `series.json` 里的 `ref` 一致），发给 Claude 检查

## 每一段

**分镜图**
1. 照 `提示词.md` 里写的框选节点（这一段出场的角色 + 用到的场景图）
2. 图片生成 → 16:9 → 复制分镜提示词 → 出 4 张
3. 挑格数对、顺序对、每格人数对、没有序号的一张，下载存成 `epNN/分镜_第N段.png`，拖回画布

**视频**
1. 按 `提示词.md` 写的顺序框选：角色 → 场景图 → 这一段的分镜（顺序决定 @图 编号）
2. 视频生成 → **Seedance 2.5** → **全能参考** → 16:9 → 30 秒 → **480p**
3. 复制视频提示词，生成
4. 下载存成 `epNN/clips/第N段.mp4`，让 Claude 跑 `review_clip.py` 检查
5. 满意了再用即梦的超清

## 省钱

- 480p 抽卡，满意了再超清
- 分镜先出对，再出视频：分镜错了视频一定错
- 只有一两个镜头不对，用 `patch` 补拍那几个，不要整段重来
- 第一集先做一段测试（选有「钻进去」转场的那段），确认转场、人物、口型、声音都行，再做其他段
